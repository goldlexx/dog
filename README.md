## Что можно узнать на сайте

Главная страница знакомит владельца собаки с территорией и условиями передержки. В одном месте собраны фотографии, описание услуг и стоимости, отзывы и ответы на частые вопросы. Из контактного блока можно перейти к обсуждению бронирования.

Перед поездкой удобно открыть отдельный калькулятор. Он помогает оценить суточную порцию и запас корма на весь срок проживания. Расчёт справочный. Индивидуальный рацион питомца стоит согласовать с ветеринаром.

## Как устроен сайт

| Технология | Что делает в проекте |
| --- | --- |
| HTML и CSS | Отдельные страницы передержки и калькулятора, стили главного экрана и секций |
| JavaScript | Поведение страниц и интерактивный расчёт |
| Webpack 5, Babel, PostCSS | Сборка двух страниц, обработка JavaScript и CSS с Autoprefixer |

Шаблоны находятся в [src/index.html](src/index.html) и [src/calculator.html](src/calculator.html). У каждой страницы своя точка входа в [src/pages/](src/pages/). Сайт использует фотографии территории и собак, а также иллюстрации, созданные с помощью ИИ.

## Локальная разработка

В каталоге репозитория с установленными Node.js и npm выполните

```sh
npm ci
npm run dev
```

Главная откроется по адресу `http://localhost:8080/`, калькулятор — по пути `/tools/food-calculator/`. Чтобы проверить расчёт, укажите параметры питомца и сравните запас корма при разной длительности пребывания.

## Сборка и публикация

`npm run build` создаёт `dist/`. В конце сборки [scripts/cname.js](scripts/cname.js) подготавливает домен, файлы для поисковых систем, карту сайта и обложку Open Graph. Исходники ведутся в ветке `main`, опубликованные файлы — в `gh-pages`. Для штатной публикации предусмотрен `npm run deploy`.
