# ДачаДог: лендинг (Алла, передержка собак)

Одностраничный сайт передержки собак за городом (под Орехово-Зуево) и в Москве.
Цель страницы: чтобы посетитель позвонил, написал в WhatsApp, Max или Telegram.

## Что на странице
- первый экран с ценой (от 2000 ₽ в сутки) и кнопками связи;
- «Обо мне», «Как это работает», цены и условия, «Что взять с собой»;
- карусель фото питомцев (адаптивная, листается пальцем на телефоне);
- отзывы с ссылками на Догси и Авито;
- FAQ и блок призыва с контактами.

## Технологии
- HTML, CSS, немного JavaScript (без jQuery и слайдеров);
- webpack 5 для сборки, Rubik из Google Fonts;
- Яндекс Метрика (счётчик 113790002).

## Запуск локально
```
npm install
npm run dev        # сервер разработки на http://localhost:8080
```
Сборка для публикации: `npm run build` (результат в папке `dist`).

## Публикация
`npm run deploy` публикует папку `dist` на GitHub Pages (ветка gh-pages).

## Структура
- `src/index.html` — вся разметка страницы;
- `src/css/base.css`, `hero.css`, `sections.css` — стили;
- `src/pages/index.js` — точка входа (подключает стили);
- `src/img/` — фото и иллюстрации (webp), логотип;
- `webpack.config.js`, `package.json` — сборка и зависимости.

## SEO и контакты
- Canonical, robots и sitemap настроены для `https://dachadog.ru/`; `scripts/cname.js` создаёт `CNAME`, `robots.txt`, `sitemap.xml` и копирует Open Graph-изображение в `dist` во время `npm run predeploy`.
- Контакты Max и Telegram в главных CTA ведут на указанные профили/ссылки; WhatsApp и телефон также оставлены рабочими.
- Отдельно проверьте регистрацию сайта и отправку sitemap в Яндекс Вебмастер и Google Search Console — это действия в аккаунтах, их проект автоматически не выполняет.

## Фото
Фото питомцев используются только с письменного согласия владельцев.
Сгенерированные изображения помечены как иллюстрации, не как реальный участок.

## Как безопасно обновить сайт (чеклист перед публикацией)

1. Сделайте копию текущей папки проекта (например, `dog-backup-2026-10-26`) перед заменой файлов.
2. Замените в копии или в рабочей папке только `src`, `scripts`, `package.json`, `webpack.config.js`, `babel.config.js`, `README.md`.
3. `npm install` (нужно один раз после изменения `package.json`).
4. `npm run dev` — откройте `http://localhost:8080` и `http://localhost:8080/tools/food-calculator/`. Проверьте главную, карусель, кнопки связи, калькулятор.
5. `npm run build` — сборка должна завершиться без ошибок (`compiled successfully`). Если нет, публиковать нельзя.
6. Только после этого `npm run deploy`. Оно публикует сайт, который видят клиенты.
7. Через 3–5 минут откройте `https://dachadog.ru/` и `https://dachadog.ru/tools/food-calculator/` с Ctrl+F5.

Если что-то сломалось после публикации, вернитесь к резервной копии и выполните шаги 5–6 ещё раз.
