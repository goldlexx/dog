# ДачаДог — лендинг передержки собак

Одностраничный сайт передержки собак: в посёлке Городищи (городской округ Покров, Владимирская область) и в Москве.
Сайт: https://dachadog.ru/

Цель страниц: чтобы посетитель позвонил или написал в WhatsApp, Max или Telegram.

## Страницы

- `/` — главная: первый экран с ценой, «Обо мне», «Как это работает», цены и условия, «Что взять с собой», галерея, отзывы, FAQ, контакты.
- `/tools/food-calculator/` — калькулятор корма: ориентир суточной нормы и расчёт запаса корма на передержку.

## Технологии

- HTML, CSS и немного JavaScript, без фреймворков.
- webpack 5, Babel, PostCSS (autoprefixer, cssnano).
- Шрифт Rubik из Google Fonts.
- Яндекс Метрика, счётчик 113790002.
- Проверено на Node.js 22.

## Запуск

```
npm install
npm run dev
```

Сервер разработки: http://localhost:8080. Калькулятор: http://localhost:8080/tools/food-calculator/

## Сборка

```
npm run build
```

Результат в папке `dist`. Сборка запускает webpack и `scripts/cname.js`, который создаёт `CNAME`, `robots.txt`, `sitemap.xml`, файл верификации Яндекса и копирует `og-cover.jpg`. Успешная сборка выводит `compiled successfully`.

## Публикация

```
npm run deploy
```

Команда сначала выполняет `npm run build` (через `predeploy`), затем публикует папку `dist` на GitHub Pages в ветку `gh-pages`.

## Структура

- `src/index.html` — разметка главной страницы.
- `src/calculator.html` — разметка страницы калькулятора.
- `src/css/` — стили: `base.css`, `hero.css`, `sections.css` (главная), `calculator.css` (калькулятор).
- `src/pages/index.js` — точка входа главной страницы (подключает стили).
- `src/pages/calculator.js` — логика калькулятора: шаги, проверка значений, расчёт, блок запаса.
- `src/img/` — фото и иллюстрации в формате webp, логотип.
- `scripts/` — `cname.js` (файлы для публикации) и `og-cover.jpg`.
- `webpack.config.js`, `babel.config.js`, `postcss.config.js`, `package.json` — сборка и зависимости.

Фото карусели лежат в `src/img/carousel/`, и на сайт попадают только они. Чтобы добавить фото, положите webp в эту папку и добавьте `<figure class="car__slide">` с `<img>` в `src/index.html`.

## Калькулятор корма

Считает ориентир суточной нормы по формуле RER = 70 × вес^0,75 (ккал в сутки) и коэффициентам активности 1,2 / 1,6 / 1,8, затем переводит энергию в граммы по калорийности корма.

Расчёт не выполняется для щенков до года, беременных, кормящих и больных собак. Результат — ориентир, а не ветеринарное назначение. Формула и коэффициенты должны быть проверены диетологом.

## Перед публикацией

1. Сделайте копию папки проекта перед заменой файлов.
2. Меняйте только `src/`, `scripts/`, `package.json`, `webpack.config.js`, `babel.config.js`, `postcss.config.js` и `README.md`.
3. Если менялся `package.json`, выполните `npm install`.
4. `npm run dev`: откройте главную и калькулятор, проверьте карусель, кнопки связи и расчёт.
5. `npm run build`: должна быть строка `compiled successfully`. Если сборка не прошла, не публикуйте.
6. `npm run deploy`.
7. Через 3–5 минут откройте https://dachadog.ru/ и https://dachadog.ru/tools/food-calculator/ с Ctrl+F5.

Если после публикации что-то сломалось, верните копию из шага 1 и повторите шаги 5–6.
