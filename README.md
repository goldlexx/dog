# ДачаДог — домашняя передержка собак

Официальный сайт сервиса домашней передержки собак «ДачаДог».

Сайт рассказывает об условиях проживания питомцев, услугах и стоимости передержки, знакомит посетителей с хозяйкой и помогает связаться для бронирования.

**Сайт:** https://dachadog.ru/

## Возможности сайта

### Главная страница
- Описание услуги домашней передержки.
- Информация об условиях проживания и стоимости.
- Фотографии территории и собак.
- Отзывы клиентов.
- Ответы на частые вопросы.
- Контактные кнопки для связи.

### Калькулятор корма

Отдельная страница с интерактивным калькулятором, который помогает:
- рассчитать ориентировочное суточное количество корма для собаки;
- определить общий запас корма на период передержки;
- оценить, сколько корма потребуется взять с собой.

**Открыть калькулятор:** https://dachadog.ru/tools/food-calculator/

Результаты расчёта носят справочный характер и не заменяют индивидуальные рекомендации ветеринарного специалиста.

## Локальная разработка

Для работы с проектом необходимы Node.js и npm.

Клонирование репозитория:

```bash
git clone https://github.com/goldlexx/dog.git
cd dog
```

Установка зависимостей:

```bash
npm install
```

Запуск локального сервера:

```bash
npm run dev
```

После запуска страницы доступны по адресам:

- Главная страница: http://localhost:8080/
- Калькулятор корма: http://localhost:8080/tools/food-calculator/

## Сборка проекта

Для создания production-версии используется команда:

```bash
npm run build
```

Готовые файлы сборки размещаются в каталоге `dist/`.

Во время сборки скрипт `scripts/cname.js` подготавливает служебные файлы сайта:
- `CNAME` — привязка домена;
- `robots.txt` — правила для поисковых роботов;
- `sitemap.xml` — карта сайта;
- файл подтверждения Яндекс Вебмастера;
- Open Graph-изображение.

## Публикация

Для публикации проекта на GitHub Pages предусмотрена команда:

```bash
npm run deploy
```

Она выполняет сборку и отправляет содержимое каталога `dist/` в ветку `gh-pages`.

## Ветки Git

- `main` — исходный код и разработка проекта.
- `gh-pages` — опубликованная версия сайта.

## SEO

Проект предусматривает:
- отдельные страницы главного сайта и калькулятора;
- метаданные страниц;
- Open Graph-разметку;
- файл `robots.txt`;
- карту сайта `sitemap.xml`;
- привязку собственного домена `dachadog.ru`.

Добавление сайта в панели поисковых систем и отправка карты сайта выполняются отдельно.
