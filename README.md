# ДачаДог — сайт передержки собак

Официальный сайт сервиса домашней передержки собак «ДачаДог». Здесь посетители могут узнать об условиях проживания питомцев, стоимости услуги, посмотреть фотографии и отзывы, а также связаться с Аллой.

**Сайт:** https://dachadog.ru/

## Возможности

### Главная страница
- Информация об услуге и хозяйке передержки.
- Условия проживания, стоимость и ответы на частые вопросы.
- Фотографии собак и отзывы клиентов.
- Контакты и кнопки связи.

### Калькулятор корма
Отдельная страница для ориентировочного расчёта:
- суточного количества корма;
- количества корма на весь период передержки.

**Калькулятор:** https://dachadog.ru/tools/food-calculator/

Расчёт носит справочный характер и не заменяет рекомендации ветеринарного специалиста.

## Технологии

- HTML5, CSS3, JavaScript.
- Webpack 5 — сборка проекта.
- Babel — обработка JavaScript.
- PostCSS и Autoprefixer — обработка CSS.
- Google Fonts (Rubik).
- Яндекс Метрика.

## Локальный запуск

Требуется установленный Node.js и npm.

Клонировать репозиторий:

\`\`\`bash
git clone https://github.com/goldlexx/dog.git
cd dog
\`\`\`

Установить зависимости:

\`\`\`bash
npm install
\`\`\`

Запустить сервер разработки:

\`\`\`bash
npm run dev
\`\`\`

Страницы доступны по адресам:

- Главная: http://localhost:8080/
- Калькулятор: http://localhost:8080/tools/food-calculator/

## Сборка

Создать production-сборку:

\`\`\`bash
npm run build
\`\`\`

Результат сборки находится в каталоге `dist/`.

Скрипт `scripts/cname.js` подготавливает служебные файлы для домена: `CNAME`, `robots.txt`, `sitemap.xml`, файл подтверждения Яндекс Вебмастера и Open Graph-изображение.

Перед публикацией убедитесь, что сборка завершилась без ошибок.

## Публикация

Для публикации на GitHub Pages предусмотрена команда:

\`\`\`bash
npm run deploy
\`\`\`

Она отправляет содержимое `dist/` в ветку `gh-pages`.

Перед публикацией проверьте обе страницы локально и выполните успешную сборку.

**Важно:** `git push origin main` отправляет исходный код в GitHub, но сам по себе не запускает `npm run deploy`.

## Работа с Git

- `main` — основная ветка разработки.
- `gh-pages` — ветка опубликованной версии сайта.

Получить последние изменения:

\`\`\`bash
git pull origin main
\`\`\`

Проверить состояние проекта:

\`\`\`bash
git status
\`\`\`

Сохранить и отправить изменения:

\`\`\`bash
git add .
git commit -m "docs: обновить README проекта"
git push origin main
\`\`\`

Перед публикацией рекомендуется выполнить `npm run build`.

## SEO

При сборке подготавливаются:
- `CNAME` с доменом `dachadog.ru`;
- `robots.txt`;
- `sitemap.xml` с главной страницей и калькулятором;
- файл подтверждения Яндекс Вебмастера;
- Open Graph-изображение.

Добавление сайта в Яндекс Вебмастер и Google Search Console и отправка sitemap выполняются отдельно в этих сервисах.
